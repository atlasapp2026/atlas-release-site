Atlas

Delete your Atlas account

This page allows an existing Atlas account owner to permanently delete their Atlas cloud account without reinstalling the Atlas app.

This action cannot be undone.

Successful deletion removes the Atlas authentication account and Atlas cloud synchronization records owned by that account.

Atlas data already stored locally on a phone, tablet, or computer is not remotely erased by this webpage. Remove Atlas application data from those devices separately if you also want the local copy removed.

1. Verify your Atlas email

Enter the email address associated with your existing Atlas account. This page cannot create a new Atlas account.

2. Enter the verification code

Enter the six-digit code sent to the Atlas account email.

3. Confirm permanent deletion

Type DELETE exactly and then select Delete Atlas account.

Atlas requires fresh email verification before permanent cloud account deletion. The temporary authenticated deletion session is kept only in this webpage's memory and is not intentionally saved to browser storage.
